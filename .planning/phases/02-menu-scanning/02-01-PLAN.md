  <action>
**src/stores/useMenuStore.ts** -- Zustand store (no persistence, in-memory only):
- State: `items: MenuItem[]`, `isProcessing: boolean`, `error: string | null`
- Actions: `setItems(items)` (also clears processing+error), `setProcessing(bool)`, `setError(string|null)`, `clear()`
- Follow the exact pattern from RESEARCH.md Pattern 1

**src/services/gemini.ts** -- Direct fetch to Gemini 2.5 Flash REST API:
- Export `extractMenuItems(base64Image: string, apiKey: string, signal?: AbortSignal): Promise<{items: RawMenuItem[]}>`
- URL: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${apiKey}`
- Send base64 image as `inline_data` with `mime_type: 'image/jpeg'`
- Use `generationConfig.responseMimeType: 'application/json'` and `responseJsonSchema` matching: items array with name (required), description, price (nullable number), category
- Prompt: instruct Gemini to extract ALL menu items including those with missing fields, preserve categories
- Parse response: `data.candidates[0].content.parts[0].text` -> JSON.parse
- Throw on non-200 status or missing candidates

**src/constants/fallbackMenu.ts** -- Hardcoded demo fallback:
- Export `FALLBACK_MENU: MenuItem[]` with ~12-15 realistic restaurant items across categories (Appetizers, Mains, Desserts, Drinks)
- Each item has a UUID-style id, name, description, price, and category
- Include some items with calories and dietaryTags to exercise those fields
- This is the safety net for demo day -- make it look like a real Italian/American restaurant menu

**src/services/menuParser.ts** -- Orchestration layer:
- Module-level `let forceFallback = false`
- Export `toggleForceFallback()` and `isForceFallback()` for the hidden dev toggle
- Export `parseMenuPhoto(base64: string, apiKey: string): Promise<MenuItem[]>`
  - If forceFallback, return FALLBACK_MENU immediately
  - Otherwise: create AbortController with 15-second setTimeout, call extractMenuItems with signal
  - On success: clearTimeout, normalize items (generate UUID ids with `Math.random().toString(36).slice(2)`, default description to empty string, default price to 0 with "N/A" note in description, default category to "Uncategorized")
  - On any error (network, timeout, parse): console.warn with error, return FALLBACK_MENU silently
- The caching pattern (try API, catch -> fallback) should be generic enough to reuse in Phase 3 for recommendations per user decision

Do NOT use @google/generative-ai SDK -- it crashes in React Native. Use direct fetch() only.
