Create three files:

**src/stores/useRecommendationStore.ts** -- Zustand store following useMenuStore pattern:
- State: `recommendations: Recommendation[]`, `isLoading: boolean`, `error: string | null`, `selectedMoodId: string | null`, `isSurprise: boolean`
- Actions: `setRecommendations(recs: Recommendation[])`, `setLoading(loading: boolean)`, `setError(error: string | null)`, `setMood(moodId: string, isSurprise: boolean)`, `toggleSaved(recId: string)` (flips the `saved` boolean on a recommendation), `getSavedItems(): Recommendation[]` (getter for saved items), `clear()`

**src/services/claude.ts** -- Claude Opus 4.6 API client using direct fetch() (NOT an SDK -- Node.js SDKs crash in React Native per CLAUDE.md):
- Export `generateRecommendations(menuItems: MenuItem[], moodId: string, apiKey: string): Promise<Recommendation[]>`
- POST to `https://api.anthropic.com/v1/messages` with `x-api-key` header, `anthropic-version: 2023-06-01`, `anthropic-dangerous-direct-browser-access: true`
- Model: `claude-sonnet-4-20250514` (use Sonnet for speed -- Opus would be too slow for a demo)
- System prompt: instruct the model to act as a food recommendation expert. Given a menu and mood, return 3-5 dishes as JSON array with fields: `menuItemId` (matching the MenuItem.id), `matchPercent` (70-99), `reasoning` (1-2 witty sentences explaining why this dish matches the mood), `foodEmoji` (single food emoji matching the dish type), `crowdFavePercent` (60-95, plausible fake popularity), `popularityTag` (e.g., "Chef's Pick", "Hidden Gem", "Crowd Fave")
- Response format: request JSON output using Claude's system prompt instruction to return valid JSON array only, parse the text response with JSON.parse
- 20s timeout with AbortController (same pattern as gemini.ts)
- On any failure, log warning and return fallback data from FALLBACK_RECOMMENDATIONS for the given moodId
- Include `toggleForceFallback()` and `isForceFallback()` exports matching menuParser.ts pattern

**src/constants/fallbackRecommendations.ts** -- Hardcoded demo fallback:
- Export `FALLBACK_RECOMMENDATIONS: Record<string, FallbackReco[]>` keyed by mood id
- Each mood has 3-4 entries with: `menuItemName` (matches fallback menu items from FALLBACK_MENU), `matchPercent`, `reasoning`, `foodEmoji`, `crowdFavePercent`, `popularityTag`
- Export a function `buildFallbackRecommendations(menuItems: MenuItem[], moodId: string): Recommendation[]` that maps fallback entries to actual MenuItem objects by name matching, falling back to first N items if no name match
- Make the reasoning text witty and demo-impressive (e.g., for comfort + "Chicken Parmigiana": "Nothing says 'hug on a plate' like layers of crispy chicken buried under molten mozzarella. Your comfort food spirit animal.")
