  <action>
Replace the placeholder results.tsx with the full recommendation results screen. This is a large screen with multiple states -- implement carefully.

**On mount (useEffect):**
1. Read `selectedMoodId` and `isSurprise` from useRecommendationStore
2. Read `items` from useMenuStore (the scanned menu)
3. Read GEMINI_API_KEY from env (or use ANTHROPIC_API_KEY -- store in app.json extra or use Constants.expoConfig.extra)
4. Call `setLoading(true)`, then `generateRecommendations(items, moodId, apiKey)`
5. On success: `setRecommendations(results)`, `setLoading(false)`
6. On error: fallback is handled inside the service, so this should still work

**For the API key:** Use `expo-constants` to read from `app.json > extra > anthropicApiKey`. Add the key to app.json extra field. If no key found, immediately use fallback.

**Loading state:**
- Show mood emoji + "Finding your perfect matches..." text
- Subtle pulsing animation on the emoji using reanimated withRepeat + withTiming opacity 0.5-1.0
- Background: colors.bgWarm

**Standard results state (isSurprise = false):**

Header section:
- BackButton (floating)
- Mood pill badge at top: coral background, white text with mood emoji + mood label (e.g., "Comfort Food")
- Heading: "Your picks" in Bold 28-32px white
- Subtext: "Ranked by mood match" in Regular 14px gray

Recommendation cards (ScrollView, single column, full-width):
- Card background: colors.card (#1A1A1A), borderRadius.lg (16), padding spacing.md
- Top row: Match % badge (mint background, white bold "96% MATCH" text, borderRadius.full pill) + popularity tag pill (dark bg #374151, white text, e.g. "Chef's Pick")
- Food emoji: large (48-56px) centered or left-aligned
- Dish name: Bold 18-20px white
- Witty reasoning: Regular 14px gray, 1-2 lines
- Stats row: crowd fave bar (thin horizontal bar, coral fill to crowdFavePercent width, gray track) + "72% of diners loved this" text in 12px gray
- Price + calories row: price in Bold 20px white, calories in Regular 14px gray (e.g., "$16.99 | 650 cal")
- Dietary tags: row of small pills with dark bg (#374151), white 12px text (e.g., "vegetarian", "gluten-free") -- only show if item.dietaryTags exists and is non-empty
- Action button row: "I'll get this" pill button (coral bg, white text, borderRadius.full, height 44px)
  - Saved state: muted dark bg (#374151) with mint checkmark icon + "Saved" white text
  - On press: call `useRecommendationStore().toggleSaved(rec.id)`
  - Animate transition: scale press feedback withSpring

Cards sorted by matchPercent descending. Gap between cards: spacing.md (16px).

**Surprise Me state (isSurprise = true):**

Two-stage reveal animation:
1. **Mood roulette** (first ~2 seconds): Show a card face-down (dark card with "?" or dice emoji). Cycle through mood emojis rapidly using reanimated, slowing down to land on the randomly selected mood. Display the selected mood label when landed.
2. **Card flip** (~0.5s after roulette lands): 3D card flip animation using reanimated. The card rotates on Y axis from 0 to 180 degrees. Front face = face-down card. Back face = the single recommendation card (same layout as standard cards above).
   - Use `rotateY` transform with `useAnimatedStyle`
   - Front visible when rotateY 0-90deg (opacity 1), hidden >90deg (opacity 0)
   - Back visible when rotateY 90-180deg (adjust perspective for 3D effect)

After reveal, show two buttons below the card:
- "I'll get this" (coral, same as standard)
- "Nah, pick again" (secondary: transparent bg, coral border, coral text) -- on press, pick a new random mood, re-run the roulette + flip sequence (allow max 1 re-roll, then hide the re-roll button)

**Sticky bottom bar (both states):**
- Only visible when at least 1 item is saved (check recommendations.filter(r => r.saved).length > 0)
- Slides up from bottom using reanimated translateY animation (from +100 to 0)
- Background: colors.card, borderRadius top-left/right: borderRadius.xl (24)
- Content: "{N} items saved" text left, "View order >" coral text right (Pressable)
- On press "View order": router.push('/order')
- Padding: spacing.md horizontal, spacing.md vertical, plus safe area bottom inset

**Hidden dev toggle:** Triple-tap on the heading text to toggle force-fallback mode for recommendation service (same pattern as scan screen).
