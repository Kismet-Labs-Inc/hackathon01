# Cravr

> **WIP** — This project is a work in progress, built during a hackathon.

Cravr is a mobile-first progressive web app that eliminates dining decision fatigue. Snap a photo of a restaurant menu, pick a mood, and get AI-powered dish recommendations ranked by flavor profile match, dietary fit, and budget.

## How It Works

1. **Scan a Menu** — Take a photo or upload an image of a restaurant menu
2. **Pick a Vibe** — Choose a mood (Comfort Food, Adventurous, Impress a Date, etc.)
3. **Get Recommendations** — AI-powered cards show match scores, flavor profiles, prices, calories, and dietary info

## What Makes This Different

Cravr is **flavor-profile-first menu intelligence**. Unlike food delivery apps that rank by popularity or ratings, Cravr deconstructs each dish into taste dimensions (savory, spicy, rich, sweet, umami) and matches them to your current mood — in real-time, at the restaurant.

## Tech Stack

- **Frontend:** Next.js / React (PWA, mobile-first)
- **AI:** Google Gemini (menu OCR + flavor profile generation)
- **Target:** Mobile browsers (Chrome Android, Safari iOS)
