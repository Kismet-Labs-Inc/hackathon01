# Menu Decision Helper

> **WIP** — This project is a work in progress, built during a hackathon.

An AI-powered app that helps users decide what to eat. Point your camera at a menu or dish and instantly get:

- **Cuisine type** (Filipino, Japanese, Thai, etc.)
- **Flavor profile** (sour, spicy, savory, etc.)
- **Key ingredients**
- **Estimated price** (PHP)
- **Health indicator**

Built using the [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD).
